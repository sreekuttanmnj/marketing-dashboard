Notes & Data-Quality Caveats

Tracking gaps to be aware of

ZilMoney signup event is unreliable. The dedicated signup event (singup_zm) fires fewer than 1 time per week. The dashboard uses contact_button_click and generate_lead as lead proxies. Authoritative ZilMoney signup numbers should come from the product database.
OCW sessions are heavily weighted toward existing-user logins. The /login page accounts for ~50% of OCW sessions. "New acquisition" is better represented by the New Users column or the trial-signup event. When discussing acquisition, prefer those over raw Sessions.
The latest period (May 2026 / W21) is partial. Monthly view: May contains only data through May 17, so the May bar is roughly half a month. It will look low — that's expected. Weekly view: only complete weeks (W13-W20) are shown.

Methodology

Traffic data is pulled from the GA4 Data API with the country dimension filtered to "United States." Search data is pulled from the Google Search Console API with the country filter set to USA. Weekly view uses ISO weeks (Monday start, Sunday end), 8 complete weeks ending May 17, 2026. Monthly view uses calendar months from February through May 2026. Both OnlineCheckWriter and ZilMoney report in America/Chicago, so periods line up cleanly across brands.

Source: GA4 Data API (US-only via country=United States) + Google Search Console API (US-only via USA country filter). Pulled 2026-05-20. Re-runnable any time with no manual pipeline.
